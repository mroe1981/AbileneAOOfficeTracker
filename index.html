Set up shared data
This app uses JSONBin.io (free) so every phone with the link sees the same entries in real time. You only set this up once.
1
Go to jsonbin.io and create a free account (no credit card needed).
2
After signing in, click API Keys in the top menu. Copy your Master Key (starts with $2b$).
3
Paste it below and click Connect. A shared bin will be created automatically. Share the same HTML file with your team — everyone uses the same key.
